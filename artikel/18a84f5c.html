GitHub ermöglicht Remote-Steuerung

The GitHub Blog · 20.05.2026 · 1 Min Lesezeit

Überall produktiv sein

GitHub hat eine neue Funktion veröffentlicht, die es Entwicklern ermöglicht, ihre lokalen GitHub-Sitzungen überall fortzusetzen. Mit der Remote-Steuerung für GitHub Copilot-Sitzungen kannst du deine Arbeit in VS Code oder der CLI beginnen und sie dann von deinem Smartphone aus beenden.

Diese Funktion ist jetzt allgemein verfügbar auf github.com und GitHub Mobile. Du kannst deine Sitzungen also überall fortschreiben, egal ob du zu Hause, im Büro oder unterwegs bist.

Vorteile der Remote-Steuerung

Die Remote-Steuerung bietet viele Vorteile für Entwickler. Du kannst deine Arbeit überall fortschreiben, ohne dass du einen bestimmten Computer oder eine bestimmte Umgebung benötigst. Du kannst auch leicht mit deinem Team zusammenarbeiten, indem du deine Sitzungen teilst und gemeinsam an Projekten arbeitest.

GitHub Copilot ist ein KI-gestütztes Tool, das Entwicklern hilft, Code zu schreiben und zu bearbeiten. Mit der Remote-Steuerung kannst du Copilot überall nutzen, egal ob du auf deinem Smartphone, Tablet oder Computer bist.

Fazit

Die Remote-Steuerung für GitHub Copilot-Sitzungen ist eine großartige Funktion, die es Entwicklern ermöglicht, ihre Arbeit überall fortzusetzen. Mit dieser Funktion kannst du deine Produktivität steigern und deine Arbeit leichter und flexibler gestalten.
