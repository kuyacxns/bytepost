Python 3.14.5 veröffentlicht

Python.org · 10.05.2026 · 1 Min Lesezeit

Python 3.14.5 Release Candidate

Python 3.14.5rc1 ist ein Release-Kandidat für die fünfte Wartungsversion von 3.14 und enthält etwa 113 Bugfixes, Build-Verbesserungen und Dokumentationsänderungen seit 3.14.4.

Der Garbage Collector (GC) wurde in Python 3.14.5rc1 geändert. Der inkrementale Garbage Collector, der in Python 3.14.0-3.14.4 geliefert wurde, wurde zurück auf den generationalen Garbage Collector von 3.13 zurückgesetzt, da erheblicher Memory-Druck in Produktionsumgebungen gemeldet wurde.

Neue Funktionen in Python 3.14

Einige der wichtigsten neuen Funktionen und Änderungen in Python 3.14 sind:

  • PEP 779: Free-threaded Python ist offiziell unterstützt
  • PEP 649: Die Auswertung von Annotationen wird jetzt verzögert, was die Semantik des Verwendens von Annotationen verbessert
  • PEP 750: Template-String-Literals (t-Strings) für benutzerdefinierte Stringverarbeitung, mit der vertrauten Syntax von f-Strings
  • PEP 734: Mehrere Interpreter in der Standardbibliothek
  • PEP 784: Ein neues Modul compression.zstd, das die Zstandard-Komprimierungsalgorithmus unterstützt

Die vollständige Liste der Änderungen in Python 3.14 findet sich in der Dokumentation What’s new in Python 3.14.

Bitte beachte, dass dies eine Vorschau-Veröffentlichung ist und deren Verwendung in Produktionsumgebungen nicht empfohlen wird.

BytePost-Einordnung: Die neue Version von Python 3.14.5 bietet einige interessante Neuerungen und Verbesserungen, insbesondere im Bereich des Garbage Collectors. Es ist jedoch wichtig, diese Version sorgfältig zu testen, bevor man sie in Produktionsumgebungen einsetzt.
