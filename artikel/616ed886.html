Cloudflare integriert Claude Managed Agents

Cloudflare Blog · 25.05.2026 · 1 Min Lesezeit

Cloudflare und Anthropic kooperieren

Cloudflare hat eine Integration mit Anthropics Claude Managed Agents vorgestellt, um eine schnelle, isolierte Ausführungsumgebung für autonome Code-Lieferung bereitzustellen. Dies ermöglicht es Entwicklern, Agent-Workflows global zu skalieren, während sie streng kontrollieren, wer Zugriff auf private Backends hat, und ihre Agent-Tools und Laufzeiten leicht anpassen können.

Die neue Integration ermöglicht es dir, deine Agent-Sandboxes, Verbindungen zu privaten Diensten und die Beobachtbarkeit zu kontrollieren. Im letzten Jahr hat Cloudflares Entwicklerplattform eine Erweiterung erfahren, um mehr Entwicklern die notwendigen Tools zu geben, um Agenten im großen Maßstab auszuführen.

Details zur Integration

Zu den wichtigsten Funktionen gehören:

  • Erweiterte Sicherheit: Alle Agenten-Verkehr läuft über anpassbare Proxys.
  • Sandbox-Kontrolle und Beobachtbarkeit: Detaillierte Sandbox-Metrik und -Logs.
  • Leichtgewichtige Sandboxes: Ausführen unvertrauenswürdigen Codes in traditionellen Micro-VMs oder leichten isolierten Umgebungen.
  • Private Dienst-Verbindung: Verbindung von Agenten zu privaten internen Diensten ohne Internet-Exposition.
  • E-Mail: Jeder Agent erhält eine eigene E-Mail-Adresse und kann E-Mails senden.
  • Benutzerdefinierte Tools: Erweiterung von Agenten mit Tools ohne zusätzliche Infrastruktur.

Claude Managed Agents

Claude Managed Agents ermöglichen es Entwicklern, Agenten auf der Anthropic-Plattform einfach zu definieren und auszuführen. In diesen verwalteten Umgebungen kann Claude Dateien lesen, Befehle ausführen, im Internet browsen und Code ausführen.

Die neue Integration ermöglicht es dir, deine Agenten in einer Cloudflare-basierten Umgebung auszuführen. Du kannst deine Agenten-Sandboxes, Verbindungen zu privaten Diensten und die Beobachtbarkeit kontrollieren.
