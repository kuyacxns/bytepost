Funcom reduziert Server von Dune Awakening

Der norwegische Spieleentwickler Funcom hat angekündigt, die Anzahl der Server für das Massively Multiplayer Online Role-Playing Game (MMORPG) Dune Awakening zu reduzieren. Weniger als ein Jahr nach dem Start des Spiels werden 162 Server weltweit geschlossen.

Betroffene Spieler müssen auf neue Welten umziehen. Dieser Schritt wurde offensichtlich notwendig, um die Spielerzahlen auf den verbleibenden Servern zu konzentrieren und ein besseres Spielerlebnis zu bieten.

Hintergrund

Funcom hat keine genauen Gründe für die Reduzierung der Server angegeben, aber es ist wahrscheinlich, dass die Entscheidung aufgrund von niedrigen Spielerzahlen und hohen Betriebskosten getroffen wurde.

Die Reduzierung der Serverzahl kann für manche Spieler ein Problem darstellen, da sie möglicherweise ihre Charaktere und Fortschritte auf den geschlossenen Servern verlieren. Funcom hat jedoch angekündigt, dass die Spieler in der Lage sein werden, ihre Charaktere auf die neuen Server zu übertragen.
