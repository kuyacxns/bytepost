Rust 1.95.0 veröffentlicht

The Rust Release Team · 03.05.2026 · 2 Min Lesezeit

Rust 1.95.0 ist verfügbar

Das Rust-Team freut sich, eine neue Version von Rust, 1.95.0, anzukündigen. Rust ist eine Programmiersprache, die es jedem ermöglicht, zuverlässige und effiziente Software zu erstellen. Wenn du eine vorherige Version von Rust über rustup installiert hast, kannst du 1.95.0 mit folgendem Befehl aktualisieren: $ rustup update stable. Wenn du rustup noch nicht installiert hast, kannst du es von der entsprechenden Seite auf unserer Website herunterladen und die detaillierten Release-Notizen für 1.95.0 lesen.

Wenn du uns helfen möchtest, indem du zukünftige Versionen testest, kannst du deine lokale Installation auf den Beta-Kanal (rustup default beta) oder den Nightly-Kanal (rustup default nightly) umstellen. Bitte melde uns alle Fehler, die du findest!

Was ist in 1.95.0 Stable enthalten?

Rust 1.95 introduceiert ein neues Macro namens cfg_select!, das ungefähr wie ein Compile-Time-Match auf cfgs funktioniert. Dies erfüllt den gleichen Zweck wie das beliebte cfg-if-Crate, jedoch mit einer anderen Syntax. cfg_select! erweitert sich zur rechten Seite des ersten Arms, dessen Konfigurationsprädikat als true ausgewertet wird.

Einige Beispiele:

  • cfg_select! { unix => { fn foo() { /* unix-spezifische Funktionalität */ } } target_pointer_width = " 32 " => { fn foo() { /* non-unix, 32-Bit-Funktionalität */ } } _ => { fn foo() { /* Fallback-Implementierung */ } } }
  • let is_windows_str = cfg_select! { windows => " windows ", _ => " not windows ", };

Rust 1.88 hat let-Ketten stabilisiert. Rust 1.95 bringt diese Fähigkeit in Match-Expressionen, um bedingte Anweisungen basierend auf Mustererkennung zu ermöglichen.

Ein Beispiel:

match value { Some(x) if let Ok(y) = compute(x) => { // Sowohl `x` als auch `y` sind hier verfügbar println!(" {} , {} ", x, y); } _ => { } }
