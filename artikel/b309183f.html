Der Real Python Podcast – Episode #298

Die Episode #298 des Real Python Podcasts behandelt das Thema, wie man die Größe von Python Docker Containern reduzieren kann. Christopher Trudeau ist wieder auf der Show und teilt eine neue Charge von PyCoder's Weekly Artikeln und Projekten.

In dieser Episode wird ein Tutorial von Khuyen Tran bei CodeCut vorgestellt, das zeigt, wie man die Größe eines Python Docker Containers mit SlimToolKit reduzieren kann. Dieses Werkzeug analysiert den Container zur Laufzeit, identifiziert die verwendeten Dateien und erstellt dann ein minimales Image mit nur den benötigten Abhängigkeiten.

Ein weiteres Thema ist die Behandlung von Ausnahmen in Python. Trey Hunner schreibt in einem Artikel über die Strategie, die man verwenden sollte, um potenzielle Fehler zu handhaben. Welche Ausnahmen sollte man catchen und welche sollte man unbehandelt lassen?

Die Episode behandelt auch andere Artikel und Projekte aus der Python-Community, einschließlich neuer Veröffentlichungen, zwei PEPs, die auf 3.16 verschoben wurden, eine kritische Schwachstelle in einem Open-Source-ASGI-Framework, die manuelle Auflösung einer Lazy-Import und ein Projekt, um sensible PII-Daten zu anonymisieren.
