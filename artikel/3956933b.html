Code: Zukunft der Programmierung

Martinfowler · 13.05.2026 · 1 Min Lesezeit

Was ist Code?

Unmesh Joshi sieht Code als having zwei distinct aber verwobene Zwecke: Anweisungen für eine Maschine und ein konzeptionelles Modell des Problemraums. Er erkundet, warum es wichtig ist, eine Vokabular zu bauen, um mit der Maschine zu sprechen, wie Programmiersprachen als Denkwerkzeuge dienen und wie dies unsere Zukunft beeinflusst, wenn wir mit Large Language Models (LLMs) arbeiten.

Code hat immer zwei unterschiedliche, aber miteinander verknüpfte Zwecke erfüllt. Erstens ist Code eine Anweisung für eine Maschine. Er leitet die Berechnung, bewegt Daten, interagiert mit Speicher und koordiniert die Ausführung. In der Ära von LLMs ist dies der Teil, der kommodifiziert wird. Zweitens ist Code ein konzeptionelles Modell des Problemraums. Dies ist der Design-Aspekt. Ein gut gestalteter Code enthält nicht nur Anweisungen für die Maschine, sondern auch Konzepte für Menschen und Werkzeuge, um damit zu arbeiten.

Konzeptionelle Modelle und Vokabular

Das konzeptionelle Modell explizit zu machen, ist der tiefere Aspekt der Codierung, getrieben von der Domäne und den Anwendungsfällen, die das System ansprechen soll. Jede Domäne kommt mit etablierten Prozessen, Praktiken und vor allem mit einem gemeinsamen Vokabular. Dieses Vokabular ist dort, wo das konzeptionelle Modell sichtbar wird. Vokabular wird normalerweise als die Menge der Wörter verstanden, die in einer bestimmten Sprache oder einem bestimmten Fachgebiet verwendet werden.

Vokabular in Code

BytePost-Einordnung: Die Zukunft der Programmierung hängt stark von der Entwicklung von KI und LLMs ab. Es ist wichtig, dass Entwickler sich auf diese Veränderungen vorbereiten und ihre Fähigkeiten anpassen, um in dieser neuen Ära erfolgreich zu sein.
