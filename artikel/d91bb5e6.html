Einführung in das Bradley-Terry-Modell

Das Bradley-Terry-Modell ist ein statistisches Modell, das verwendet wird, um aus Paarvergleichen probabilistische Ranglisten zu erstellen. Dieses Modell wurde ursprünglich in den 1950er Jahren entwickelt, um die Leistung von Sportmannschaften zu bewerten.

Das Modell geht davon aus, dass die Wahrscheinlichkeit, dass ein Element einem anderen überlegen ist, direkt proportional zu seinem eigentlichen Wert ist. Dieser Wert kann als ein Skalarwert betrachtet werden, der die relative Stärke oder Leistung des Elements darstellt.

Wie funktioniert das Bradley-Terry-Modell?

Das Bradley-Terry-Modell verwendet eine einfache Formel, um die Wahrscheinlichkeit zu berechnen, dass ein Element einem anderen überlegen ist. Diese Formel lautet:

p(i > j) = (wi / (wi + wj))

wobei p(i > j) die Wahrscheinlichkeit ist, dass Element i Element j überlegen ist, und wi und wj die Skalarwerte von Element i und j sind.

Anwendung des Bradley-Terry-Modells

Das Bradley-Terry-Modell kann in verschiedenen Anwendungsbereichen verwendet werden, wie z.B. in der Sportanalyse, der politischen Analyse oder der Bewertung von Produkten.

Ein Beispiel für die Anwendung des Bradley-Terry-Modells ist die Bewertung von Fußballmannschaften. Wenn zwei Mannschaften gegeneinander antreten, kann das Bradley-Terry-Modell verwendet werden, um die Wahrscheinlichkeit zu berechnen, dass eine Mannschaft die andere besiegt.
