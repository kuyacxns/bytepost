Lösung für Node-Löschproblem

LeetCode · 10.06.2026 · 1 Min Lesezeit

Einführung

Das Problem des Node-Löschens in einer verketteten Liste ist ein häufiges Interviewthema. Normalerweise benötigt man Zugriff auf den vorherigen Knoten, um einen Knoten zu löschen. In diesem Problem wird jedoch nur der Knoten angegeben, der gelöscht werden soll. Kein Kopf, kein vorheriger Zeiger. Wie können wir ihn also entfernen? Lassen Sie uns den Trick verstehen.

Problemstatement

Schreiben Sie eine Funktion, um einen Knoten in einer einfachen verketteten Liste zu löschen. Ihnen wird nicht der Kopf der Liste gegeben. Stattdessen erhalten Sie nur den Knoten, der gelöscht werden soll.

Beispiel

Eingabe: 4 -> 5 -> 1 -> 9, Knoten = 5. Ausgabe: 4 -> 1 -> 9.

Anfangsgedanke

Normalerweise löschen wir einen Knoten wie folgt: prev.next = node.next. Aber hier haben wir keinen vorherigen Zeiger, keinen Kopf. Der übliche Löschansatz ist also unmöglich.

Schlüsselbeobachtung

Obwohl wir den aktuellen Knoten nicht direkt löschen können, können wir ihn so manipulieren, dass es aussieht, als hätte er nie existiert. Betrachten Sie: 4 -> 5 -> 1 -> 9. Wir müssen den Knoten 5 löschen. Anstatt den Knoten 5 zu entfernen, kopieren wir den Wert des nächsten Knotens in ihn. 4 -> 1 -> 1 -> 9. Jetzt entfernen wir den nächsten Knoten. 4 -> 1 -> 9. Der ursprüngliche Wert 5 ist verschwunden.

Intuition

Kopieren Sie den Wert des nächsten Knotens in den aktuellen Knoten. Überspringen Sie den nächsten Knoten. Der aktuelle Knoten verhält sich jetzt so, als wäre er gelöscht. Da das Problem garantiert, dass der angegebene Knoten nicht der letzte Knoten ist, wird immer ein nächster Knoten existieren.

class Solution { public void deleteNode (ListNode node) { ListNode cur = node.next; node.val = cur.val; node.next = cur.next; } }
