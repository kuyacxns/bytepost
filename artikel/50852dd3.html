Docusign entwickelt AI-gestütztes Framework

Getdbt · 20.05.2026 · 2 Min Lesezeit

Einleitung in das Problem

Als Entwickler von Datenanalysen weißt du, wie wichtig es ist, deine Daten vor der Produktion zu testen. Das Unternehmen Docusign hat Millionen von Kunden weltweit und benötigt daher eine zuverlässige Datenanalyse. Bei Docusign wurde jedoch festgestellt, dass traditionelle dbt-Datentests, wie z.B. nicht_null oder unique, auf existing Datenmengen angewiesen sind. Für neue Funktionen und sich entwickelnde Pipelines benötigten sie jedoch dbt-Einheitstests, die Logik validieren, indem sie Eingabedaten simulieren und erwartete Ausgaben überprüfen.

Sundar Subramanyam, Lead Data Engineer bei Docusign, stellte fest, dass die manuelle Erstellung von Einheitstests für dbt-Modelle sehr komplex und zeitaufwändig war. Die Erstellung eines einzigen Tests konnte bis zu 5 Stunden dauern. Um dieses Problem zu lösen, entwickelte Subramanyam ein AI-gestütztes Framework, das die Erstellung von dbt-Einheitstests automatisiert.

Das AI-gestützte Framework

Das Framework von Docusign verwendet GitHub Copilot (GPT-4+) und verbessert die Effizienz und Übernahme von Tests um 90%. Durch die Kombination von AI mit dbt-Tools kann Docusign nun Datenqualität zuverlässig überprüfen, bevor Produktionsdaten vorliegen. Das Framework umfasst mehrere Schritte:

  • Modell-Eingabe: Der Engineer liefert ein dbt-Modell.
  • AI-Interpretation: Ein benutzerdefinierter AI-Workflow parst die Spalten-transformationen, Joins, Filter und logische Verzweigungen.
  • Logik-Zusammenfassung: Das System erzeugt eine strukturierte Darstellung der Quelltabellen, Ausgabe-Spalten und Transformationsregeln.
  • Menschliche Überprüfung: Der Engineer überprüft und bestätigt die Interpretation.
  • Testfall-Generierung: Das Framework erzeugt positive und negative Testfälle, einschließlich simulierter Eingabedaten.
  • YAML-Ausgabe: Das System produziert eine gültige dbt-Einheitstest-Datei.

Durch die Verwendung dieses Frameworks konnte Docusign die Zeit, die für die Erstellung von dbt-Einheitstests benötigt wird, von 5 Stunden auf 30 Minuten reduzieren.

Fazit

Das AI-gestützte Framework von Docusign ist ein Beispiel dafür, wie künstliche Intelligenz eingesetzt werden kann, um die Effizienz und Qualität von Datenanalysen zu verbessern. Durch die Automatisierung von Einheitstests kann Docusign nun schnellere und zuverlässigere Datenanalysen durchführen.

Es zeigt, dass künstliche Intelligenz in der Lage ist, komplexe Aufgaben zu automatisieren und so die Produktivität von Entwicklern zu steigern.
