Cloudflare integriert Claude Compliance API

Cloudflare Blog · 28.05.2026 · 1 Min Lesezeit

Neue Integration für mehr Sicherheit

Cloudflare hat eine neue Integration mit der Claude Compliance API bekannt gegeben. Diese Integration ermöglicht es Sicherheitsteams, die Aktivitäten von Claude Enterprise direkt im Cloudflare-Dashboard zu überwachen. Damit können Unternehmen ihre Claude-Nutzung besser kontrollieren und sicherstellen, dass ihre Daten geschützt sind.

Die Claude Compliance API bietet Sicherheits- und Compliance-Teams programmaticen Zugriff auf Sicherheits-relevante Daten über ihre Claude-Organisationen, Arbeitsbereiche und Nutzung. Cloudflare CASB (Cloud Access Security Broker) nutzt diese API, um Sicherheitsinformationen ohne Inline-Verkehrskontrolle oder Endgeräteagenten zu bereitstellen.

Die Herausforderung der AI-Sicherheit

Die schnelle Adoption von KI-Anwendungen hat es Unternehmen schwer gemacht, zu sehen, wie Benutzer mit genehmigten und nicht genehmigten Anwendungen interagieren. Diese Interaktionen unterscheiden sich von traditionellen SaaS-Anwendungen, da Benutzer Dateien hochladen, freie Prompts teilen und Anbieter Inhalte generieren, die sensible Daten enthalten können.

Cloudflare CASB hilft, dieses Problem zu lösen, indem es Unternehmen eine umfassende Sicht auf ihre SaaS-Anwendungen bietet. Durch eine API-Integration kann Cloudflare CASB Anwendungen überwachen und Sicherheitsrisiken erkennen, ohne dass Endgeräteagenten erforderlich sind.

Die Vorteile der Integration

Die Integration von Cloudflare CASB mit der Claude Compliance API bietet Unternehmen eine Reihe von Vorteilen, darunter:

  • Erhöhte Sichtbarkeit und Kontrolle über die Claude-Nutzung
  • Automatisierte Erkennung von Sicherheitsrisiken und -vorfällen
  • Verbesserte Compliance und Risikomanagement

Indem Unternehmen die Claude Compliance API mit Cloudflare CASB integrieren, können sie ihre Sicherheits- und Compliance-Anforderungen besser erfüllen und ihre Daten effektiv schützen.
