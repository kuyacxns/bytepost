Sicherheitslücke in Cargo entdeckt

Rust Security Response Team · 07.06.2026 · 2 Min Lesezeit

Sicherheitswarnung für Cargo (CVE-2026-5223)

Das Rust Security Response Team wurde informiert, dass Cargo Symlinks innerhalb von Crate-Tarballs von Drittanbieter-Registries falsch gehandhabt hat. Dies ermöglichte es einem bösartigen Crate, den Quellcode eines anderen Crates aus dem gleichen Registry zu überschreiben.

Diese Sicherheitslücke wird als CVE-2026-5223 bezeichnet. Die Schwere der Sicherheitslücke wird als mittel für Benutzer von Drittanbieter-Registries eingestuft. Benutzer von crates.io sind nicht betroffen, da crates.io das Uploaden von Crates mit Symlinks verbietet.

Überblick

Wenn ein Crate erstellt wird, extrahiert Cargo seinen Quellcode in einem lokalen Cache (gespeichert in ~/.cargo), der für zukünftige Erstellungen wiederverwendet wird. Cargo enthält Schutzmechanismen, um zu verhindern, dass Dateien außerhalb des Cache-Verzeichnisses des Crates extrahiert werden.

Es wurde festgestellt, dass es möglich ist, einen bösartigen Tarball zu erstellen, der Dateien auf einem tieferen Level als das Cache-Verzeichnis des Crates extrahieren kann. Aufgrund der Struktur des Caches ermöglichte dies dem bösartigen Crate, den Cache von anderen Crates aus dem gleichen Registry zu überschreiben.

Minderung

Rust 1.96.0, das am 28. Mai 2026 veröffentlicht wird, wird Cargo aktualisieren, um die Extraktion von Symlinks in Crate-Tarballs abzulehnen, unabhängig davon, ob sie von crates.io (das bereits Symlinks verbietet) oder Drittanbieter-Registries stammen. Es ist zu beachten, dass Cargo nie Symlinks hinzugefügt hat, wenn cargo package oder cargo publish ausgeführt wurde, sodass der Einfluss minimal sein sollte.

Benutzer, die nicht auf die neueste Rust-Version aktualisieren können, werden empfohlen, den Inhalt ihrer Registries auf Symlinks zu überprüfen und ihre Registry so zu konfigurieren, dass sie Symlinks ablehnen (falls diese Option verfügbar ist).
