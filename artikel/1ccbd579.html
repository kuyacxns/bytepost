AWS Transform feiert 1-Jahres-Jubiläum

AWS Blog · 28.05.2026 · 1 Min Lesezeit

AWS Transform: Ein Jahr Erfolg

Vor einem Jahr hat AWS AWS Transform für .NET, Mainframe und VMware-Workloads gestartet, den ersten agentic-AI-Service, der speziell für die Modernisierung von Unternehmensanwendungen im großen Maßstab entwickelt wurde. Auf der re:Invent 2025 wurde AWS Transform Custom vorgestellt, das es Organisationen ermöglicht, Code im großen Maßstab mithilfe von AWS-gesteuerten und benutzerdefinierten Transformationen zu modernisieren und umzuwandeln.

Sie können Sprachversionen aktualisieren, Frameworks migrieren, die Leistung optimieren und Codebasen mithilfe von Transformationen analysieren, die bereit zur Verwendung sind oder benutzerdefiniert werden können, um die spezifischen Anforderungen Ihrer Organisation zu erfüllen. Außerdem wurden Full-Stack-Windows-Modernisierungsfunktionen und Reimagine-Funktionen sowie automatisierte Testfunktionen für Mainframes eingeführt.

In 12 Monaten haben Tausende von Kunden Hunderttausende von Servern migriert, 1,6 Millionen Stunden gespart und 4,5 Milliarden Codezeilen mit AWS Transform verarbeitet. Anlässlich des 1-Jahres-Jubiläums sind AWS-Transform-Agents nun in Kiro, Claude, Cursor und Codex verfügbar, einschließlich des Agent-Builder-Toolkits Kiro Power für die Erstellung benutzerdefinierter Transformations-Agents.

Neue Funktionen und Updates

Im Rahmen der Feierlichkeiten wurden auch einige neue Funktionen und Updates angekündigt, darunter:

  • Die allgemeine Verfügbarkeit von Claude Platform auf AWS
  • Amazon EC2 M3 Ultra Mac-Instanzen
  • Amazon Redshift RG-Instanzen, die von AWS Graviton angetrieben werden
  • Amazon Bedrock Advanced Prompt Optimization
  • AWS Security Agent mit vollständiger Code-Scanning-Funktion (Vorschau)
  • AWS Interconnect – Multicloud-Konnektivität mit Oracle Cloud Infrastructure (Vorschau)

Um mehr über die Entwicklungen von AWS Transform und den neuen Funktionen zu erfahren, kannst du die offizielle AWS-Blog-Beiträge besuchen.
