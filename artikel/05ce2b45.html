Python 3.15 Beta 1 veröffentlicht

Python.org · 16.05.2026 · 1 Min Lesezeit

Python 3.15 Beta 1 ist da!

Die erste Beta-Version von Python 3.15 ist veröffentlicht worden. Diese Version ist die erste von vier geplanten Beta-Versionen und markiert den Beginn der Feature-Einfrierung. Die Community wird aufgerufen, die neue Version zu testen und Fehler zu melden, um sicherzustellen, dass die endgültige Version stabil und funktional ist.

Die wichtigsten Neuerungen in Python 3.15 sind:

  • PEP 810: Explicit lazy imports für schnellere Startzeiten
  • PEP 814: Addiert einen frozendict-Build-in-Typ
  • PEP 661: Addiert einen sentinel-Build-in-Typ
  • PEP 799: Ein dediziertes Profiling-Paket für die Organisation von Python-Profiling-Tools
  • PEP 799: Tachyon: Ein High-Frequency-Statistical-Sampling-Profilierer
  • PEP 831: Frame-Pointers sind standardmäßig aktiviert für verbesserte Systemüberwachung
  • PEP 798: Entpacken in Comprehensions
  • PEP 686: Python verwendet UTF-8 als Standardcodierung
  • PEP 829: Paket-Startkonfigurationsdateien
  • PEP 728: TypedDict mit typisierten Extra-Elementen
  • PEP 747: Annotieren von Typformen mit TypeForm
  • PEP 800: Disjunkte Basen im Typsystem
  • PEP 782: Ein neuer PyBytesWriter-C-API zum Erstellen von Python-Bytes-Objekten
  • PEP 803, 820, 793: Stabile ABI für free-threaded Builds und verwandte C-API

Der JIT-Compiler wurde signifikant verbessert, mit einer durchschnittlichen Leistungssteigerung von 8-9% auf x86-64-Linux und 12-13% auf AArch64-macOS.

Die offiziellen Windows-64-Bit-Binärdateien verwenden nun den tail-calling-Interpreter.

Fehlermeldungen wurden verbessert und es gibt mehr Farben.

Die nächste Vorabversion von Python 3.15 wird 3.15.0b2 sein, die für den 2. Juni 2026 geplant ist.
