Spotify baut natürliche Schnittstelle für Ads API

Spotify Engineering · 24.05.2026 · 1 Min Lesezeit

Einführung

Spotify hat eine natürliche Schnittstelle zur Spotify Ads API entwickelt. Diese Schnittstelle ermöglicht es Benutzern, Anzeigenkampagnen mit einfachen Sprachbefehlen zu erstellen. Die Schnittstelle basiert auf der Claude-Code-Plugin-Architektur und verwendet Markdown-Dateien und eine OpenAPI-Spezifikation.

Die Plugin-Architektur

Die Plugin-Architektur besteht aus vier Komponententypen: Skills, Agents, Hooks und Settings. Skills definieren die Befehle, Agents verarbeiten die natürliche Sprache, Hooks interceptieren Tool-Aufrufe und Settings speichern Benutzereinstellungen.

Die Funktionsweise

Der Benutzer kann Anzeigenkampagnen mit einfachen Sprachbefehlen wie "Erstelle eine Audio-Kampagne für 25-44-Jährige in den USA mit einem Budget von 100 Dollar pro Tag" erstellen. Der Agent decomponiert diesen Befehl in die notwendigen API-Aufrufe, um die Kampagne zu erstellen.

Warum diese Technologie-Wahl

Die Entscheidung für Claude Code und die OpenAPI-Spezifikation ermöglichte es, die Schnittstelle schnell und einfach zu entwickeln. Die Verwendung von Markdown-Dateien und der OpenAPI-Spezifikation ermöglicht es, die Schnittstelle einfach zu konfigurieren und zu erweitern.

Die Spotify Ads API v3 hat über 30 Ressourcentypen, verschachtelte Zielgruppenstrukturen und mehrstufige Entitäts-Hierarchien, was die Erstellung von Anzeigenkampagnen kompliziert macht. Die neue Schnittstelle soll diese Komplexität reduzieren und es Benutzern ermöglichen, Anzeigenkampagnen mit einfachen Sprachbefehlen zu erstellen.
