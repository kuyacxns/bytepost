Drasi nutzt GitHub Copilot

Microsoft Azure Blog · 12.04.2026 · 1 Min Lesezeit

Drasi und GitHub Copilot

Drasi hat GitHub Copilot eingesetzt, um Dokumentationsfehler zu finden. GitHub Copilot ist ein KI-gestützter Code-Assistent, der Entwicklern hilft, Code zu schreiben und zu überprüfen.

Microsoft setzt auch auf KI-Agenten und Drasi, um offene Dokumentationen genau und funktionsfähig zu halten. Die Agent Governance Toolkit ist ein Open-Source-Toolkit, das Laufzeit-Sicherheit für KI-Agenten bietet.

Dokumentationsfehler finden

Drasi hat GitHub Copilot genutzt, um Dokumentationsfehler in offenen Quellcode-Repositorys zu finden. Durch die Verwendung von KI-Algorithmen kann GitHub Copilot automatisch Code überprüfen und Fehler finden.

Die Agent Governance Toolkit bietet OS-ebene Sicherheit, Vertrauen und Konformität für autonome KI-Agenten. Sie ermöglicht es Entwicklern, ihre KI-Modelle zu überwachen und zu steuern, um sicherzustellen, dass sie korrekt und sicher arbeiten.

Fazit

Die Kombination aus GitHub Copilot und der Agent Governance Toolkit bietet Entwicklern ein leistungsstarkes Werkzeug, um Dokumentationsfehler zu finden und ihre KI-Modelle zu überwachen.
