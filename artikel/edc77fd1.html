TypeScript 6.0 veröffentlicht

TypeScript · 29.05.2026 · 2 Min Lesezeit

Was ist TypeScript?

TypeScript ist eine Sprache, die auf JavaScript aufbaut, indem sie Syntax für Typen hinzufügt. Dies ermöglicht eine Typüberprüfung, um Fehler zu erkennen und eine reiche Editor-Tooling zu bieten. Wenn du TypeScript noch nicht kennst, kannst du mehr über TypeScript und wie du loslegst auf der TypeScript-Website erfahren.

Mit der Veröffentlichung von TypeScript 6.0 ist es möglich, diese Version über npm mit dem folgenden Befehl zu installieren: npm install -D typescript

Was ist neu in TypeScript 6.0?

TypeScript 6.0 ist eine einzigartige Veröffentlichung, da es sich um die letzte Version handelt, die auf dem aktuellen JavaScript-Codebase basiert. Wie bereits im letzten Jahr angekündigt, arbeiten wir an einer neuen Codebase für den TypeScript-compiler und den Language-Service, der in Go geschrieben ist und die Geschwindigkeit von nativem Code und Shared-Memory-Multi-Threading nutzt. Diese neue Codebase wird die Grundlage für TypeScript 7.0 und darüber hinaus bilden.

TypeScript 6.0 dient als Brücke zwischen TypeScript 5.9 und 7.0. Daher sind die meisten Änderungen in TypeScript 6.0 darauf ausgerichtet, die Anpassung und Vorbereitung auf die Verwendung von TypeScript 7.0 zu erleichtern.

Neue Funktionen und Verbesserungen

Seit der Beta- und RC-Veröffentlichung von TypeScript 6.0 haben wir einige bemerkenswerte Änderungen vorgenommen, die hauptsächlich darauf abzielen, das Verhalten von TypeScript 7.0 zu imitieren. Eine dieser Anpassungen betrifft die Typüberprüfung für Funktionsausdrücke in generischen Aufrufen, insbesondere in generischen JSX-Ausdrücken.

Wir haben auch die Deklaration von Import-Assertion-Syntax (z.B. import ... assert {...}) auf Import()-Aufrufe wie import(..., { assert: {...}}) erweitert.

Des Weiteren haben wir die DOM-Typen aktualisiert, um die neuesten Web-Standards widerzuspiegeln, einschließlich einiger Anpassungen an den Temporal-APIs.

Less Context-Sensitivity

Beispielsweise:

declare function callIt(obj: { produce: (x: number) => T, consume: (y: T) => void, }): void;

callIt({ produce: (x: number) => x * 2, consume: y => y.toFixed(), });

callIt({ consume: y => y.toFixed(), produce: (x: number) => x * 2, });

Hier kann TypeScript den Typ von y im consume-Funktion anhand des abgeleiteten Typs T aus dem produce-Funktion ableiten, unabhängig von der Reihenfolge der Eigenschaften.

Wenn jedoch diese Funktionen in Methoden-Syntax geschrieben werden:

declare function callIt(obj: { produce: (x: number) => T, consume: (y: T) => void, }): void;

callIt({ produce(x: number) { return x * 2; }, consume(y) { return y.toFixed(); }, });

callIt({ consume(y) { return y.toFixed(); }, produce(x: number) { return x * 2; }, });

Der zweite Aufruf von callIt ergibt einen Fehler, da TypeScript nicht in der Lage ist, den Typ von y im consume-Method zu ableiten.

BytePost-Einordnung: Die Veröffentlichung von TypeScript 6.0 ist ein wichtiger Schritt auf dem Weg zu TypeScript 7.0. Entwickler sollten sich auf die neuen Funktionen und Verbesserungen einstellen und TypeScript 7.0 ausprobieren, um die Vorteile der neuen Codebase zu nutzen.
