Go-Entwickler bekommen neue API

The Go Blog · 26.05.2026 · 2 Min Lesezeit

Die neue pkg.go.dev API

Seit ihrer Einführung hat sich pkg.go.dev als die primäre Ressource für Paketdokumentation und -entdeckung in der Go-Community etabliert. Zunächst wurden die Schaffung einer umfassenden und hoch zugänglichen Web-Oberfläche für Benutzer priorisiert, aber das Bedürfnis nach programmatischem Zugriff ist immer deutlicher geworden.

Entwickler, die Tools, IDE-Integrationen und automatisierte Workflows erstellen, mussten in der Vergangenheit auf fragile Workarounds wie Web-Scraping zurückgreifen, um auf diese Daten zuzugreifen. Um diese sich entwickelnden Anforderungen besser zu erfüllen, wird die Plattform erweitert, um einen robusten, direkten Zugriff auf die Informationen zu bieten, die die Community benötigt.

Heute wird die offizielle pkg.go.dev-API vorgestellt – ein Dienst für die Abfrage von Metadaten über veröffentlichte Go-Module. Dieser Launch ist eine direkte Reaktion auf jahrelanges Community-Feedback.

Die Dienstschnittstelle

Die API verwendet eine stateless, GET-only-Architektur, die für Stabilität und effizientes Caching ausgelegt ist. Primäre Endpunkte sind derzeit unter dem Pfad /v1beta gehostet. Nach einer Phase des Community-Feedbacks und bestätigter Stabilität ist geplant, zu einer offiziellen v1-Veröffentlichung überzugehen.

Für eine vollständige interaktive Referenz aller Endpunkte, Abfrageparameter und Antwortformate siehe die pkg.go.dev/api-Spezifikation. Der maschinenlesbare API-Vertrag wird auch direkt als OpenAPI-Spezifikation veröffentlicht.

Kernendpunkte

  • /v1beta/package/{path} – Informationen über das Paket unter {path}.
  • /v1beta/module/{path} – Informationen über das Modul unter {path}.
  • /v1beta/versions/{path} – Versionen des Moduls unter {path}.
  • /v1beta/packages/{path} – Informationen über Pakete des Moduls unter {path}.
  • /v1beta/search?q={query} – Suchergebnisse für eine bestimmte Abfrage.
  • /v1beta/symbols/{path} – Liste der von dem Paket unter {path} deklarierten Symbole.
  • /v1beta/imported-by/{path} – Pfade der Pakete, die das Paket unter {path} importieren.
  • /v1beta/vulns/{path} – Sicherheitslücken des Moduls oder Pakets unter {path}.

Ein Designprinzip für diese API ist „Präzision über Bequemlichkeit“.

Um Versionen anzugeben, können für Endpunkte, die Paket-, Modul- oder Symbolinformationen abrufen, die optionalen Abfrageparameter version verwendet werden. Die API gibt standardmäßig Informationen über die neueste Version des Moduls oder Pakets zurück.

Beispiel für eine rohe API-Anfrage, um strukturierte Metadaten für ein bestimmtes Paket direkt abzurufen (mit jq für die Formatierung):

$ curl https://pkg.go.dev/v1beta/package/github.com/google/go-cmp/cmp | jq

BytePost-Einordnung: Die neue pkg.go.dev-API bietet Entwicklern eine einfache und sichere Möglichkeit, auf Paket- und Moduldaten zuzugreifen, was die Entwicklung von Tools und Workflows in der Go-Community erheblich verbessern wird.
